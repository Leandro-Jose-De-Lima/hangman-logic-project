# 🪓 Hangman Game - Logic Project (Java CLI)

This is a functional **Hangman Game** developed to run in the terminal. The main goal of this project was to practice and consolidate fundamental **Programming Logic** concepts in Java before moving into Object-Oriented Programming (OOP).

## 🚀 Technologies and Concepts Applied

In this project, I focused on building a solid foundation using:
* **User Input Handling:** Utilizing the `Scanner` class for interactive gameplay.
* **Control Flow:** Implementation of `while` loops for the game engine and `if/else` statements for win/loss conditions.
* **Data Structures:** Managing secret words and user guesses using **Arrays** and **Strings**.
* **Randomization:** Using the `Random` class to select words from a predefined list.
* **Procedural Programming:** Organizing code into static methods to maintain readability and clean code principles.
